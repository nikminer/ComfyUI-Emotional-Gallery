# ComfyUI Emotional Gallery

[English](README.md) | Русский

**v1.0.0 — первый стабильный релиз.** [Описание релиза](CHANGELOG.md)

Отдельное окно с генератором и кешем 131 встроенного и своих выражений лица для Character LoRA. Открывается кнопкой **◉ Expressions** в интерфейсе ComfyUI. Ноды расширения скрыты из библиотеки, поиска и меню добавления: пользователь работает только через окно галереи. Интерфейс всегда на английском, без определения языка и переключателя. Названия файлов, ваши промпты и имена своих эмоций сохраняются как введены.

![ComfyUI Emotional Gallery: группы выражений и сворачиваемые настройки](https://raw.githubusercontent.com/nikminer/ComfyUI-Emotional-Gallery/main/docs/images/gallery.png)

## Установка

Из папки `ComfyUI/custom_nodes` выполните:

```powershell
git clone https://github.com/nikminer/ComfyUI-Emotional-Gallery.git comfyui_emotional_gallery
```

Или скопируйте папку проекта в `ComfyUI/custom_nodes/comfyui_emotional_gallery`. Перезапустите ComfyUI и обновите страницу браузера (Ctrl+F5). Новые Python-пакеты и сборка JavaScript не нужны: расширение использует зависимости ComfyUI. Для обновления выполните `git pull` в папке расширения, перезапустите ComfyUI и обновите страницу. Не устанавливайте вторую копию рядом с существующей.

В Windows можно установить командой из папки проекта:

```powershell
.\install.ps1 -CustomNodesPath 'C:\path\to\ComfyUI\custom_nodes'
```

## Генерация и выбор

У кнопки **◉ Expressions** есть ручка с точками. Перетащите её в удобное место. Во время перемещения в верхней панели ComfyUI появляется область **Dock Expressions**: отпустите ручку над ней, чтобы встроить кнопку в панель. Потяните закреплённую кнопку за точки, чтобы снова сделать её плавающей. Положение и закрепление сохраняются в этом браузере. С клавиатуры: фокус на ручке, Enter — закрепить или открепить, стрелки — перемещать на 10 пикселей, Shift + стрелки — на 1 пиксель; Escape отменяет текущее перетаскивание.

1. Откройте **◉ Expressions**, выберите **Model profile**: Anima, Illustrious / NoobAI, Pony, SDXL, SD 1.5, Flux.1 Dev / Schnell, SD3 / SD3.5, Qwen Image или Z-Image Base / Turbo. Окно покажет нужные модели и энкодеры и предложит начальные параметры. Совместимые файлы с нестандартными именами можно выбрать вручную. При отсутствии подходящих файлов поля остаются пустыми. Для прежних наборов доступен профиль **SD 1.5 / SDXL (saved settings)**.
2. Нажмите **Character LoRA**: прямо в списке откроется поиск. Введите имя, папку или несколько слов, например `mayuri anima`. Регистр, подчёркивания и дефисы не мешают поиску. Выберите результат мышью либо стрелками ↑/↓ и Enter; Escape закрывает список. Под названием показана папка LoRA. Ввод запроса сохраняет текущего персонажа до выбора результата. Кнопка **Refresh models and LoRAs** перечитывает каталог, включая вложенные папки и extra model paths.
3. Проверьте trigger words персонажа и базовый портретный промпт. Расширение читает локальные метаданные LoRA Manager, rgthree, описание с пометкой Trigger words и явные activation words из заголовка safetensors. Теги отображаются кнопками: синие включены; нажатие добавляет или убирает тег из промпта. Group mode переключает целые группы. All on / All off включают или выключают все найденные теги; Reload tags перечитывает метаданные. Поле ниже позволяет добавить свои слова и отредактировать выбранные. Если поле пустое и сохранённых переключений нет, автоматически выбирается первая группа; альтернативные наряды можно включить отдельно. Переключения запоминаются для каждой LoRA в этом браузере. Сохранённый набор восстанавливает свои точные trigger words. Укажите силу LoRA, размер, шаги, CFG, sampler, scheduler и seed. Для Anima есть shift; начальные параметры: 768×768, 30 шагов, CFG 4, euler_ancestral / simple, shift 3, сила CLIP 0.
4. Нажмите **Create gallery**. Расширение поставит в обычную очередь ComfyUI по одной генерации на каждую эмоцию. Одинаковый seed помогает сравнивать выражения при похожей композиции.
5. Нажмите на карточку, чтобы выбрать эмоцию. Под ней отображаются теги выражения лица; **Copy expression** копирует эти теги. Полный положительный промпт с персонажем и базовым описанием по-прежнему используется для генерации и сохраняется в кеше.

## Категории и удаление наборов

В библиотеке два направления: вкладка **SFW** с 99 встроенными выражениями и **NSFW** с 32. Внутри каждого направления находятся сворачиваемые подкатегории с похожей мимикой. Названия карточек не содержат префиксов SFW / NSFW: **Neutral**, **Smile**, **Ahegao**. Категории Basic нет; промпты, ID и изображения не меняются.

В **SFW** доступны Neutral, Focus, Fatigue & boredom, Smile, Affection, Smirk, Playful, Blush, Pout & sulking, Sadness, Anger, Surprise и Worry. В **NSFW** — Ahegao, Torogao, Ohogao, Ohhoai, Ikigao, Aroused и Seductive smile. Например, группа Ahegao содержит основной вариант, закатившиеся глаза, слёзы и улыбку, сердечки в зрачках и зажмуренные глаза. Похожие комбинации без специального тега распределены по ближайшему визуальному семейству.

Повседневная мимика дополнена 50 выражениями: спокойствие, серьёзность, внимание, сосредоточенность, усталость, зевок, скука, облегчение, разочарование, недовольство, любопытство, скепсис, виноватый вид и другие. В **Pout & sulking** восемь вариантов: дуется, надуты обе щеки, надута одна щека, угрюмо дуется, обида, упрямство, игриво дуется и дуется со слезами на глазах. Чтобы добавить превью в существующий набор, нажмите **Generate missing** в нужной подкатегории.

Нажмите заголовок подкатегории, чтобы свернуть или развернуть её; состояние сохраняется в этом браузере. **Expand all** / **Collapse all** открывают или сворачивают все подкатегории текущего направления. Эти кнопки и **Generate missing in group** находятся в отдельной панели над прокручиваемым списком и всегда остаются видны. Позиция прокрутки сохраняется при переключении SFW / NSFW в открытом окне; повторный выбор той же вкладки не сбрасывает список. **Expand all** / **Collapse all** возвращают список к началу. **Generate missing** внутри подкатегории генерирует только её недостающие карточки. Свои эмоции можно сразу отнести к выбранной подкатегории. Старые свои эмоции без подкатегории находятся в **Custom** своего направления; старые категории автоматически отображаются в SFW. Пустые подкатегории скрыты.

Вкладки SFW / NSFW всегда находятся над карточками; выберите нужное направление без прокрутки остальных выражений. Выбранная вкладка сохраняется в этом браузере. Счётчики показывают готовые карточки. **Generate missing in group** ставит в очередь только отсутствующие выражения выбранного направления; общая кнопка генерации включает весь набор. Вкладки доступны с клавиатуры: стрелки влево/вправо, Home и End.

Категория **NSFW** содержит 32 пресета выражения лица. В дополнение к Ahegao, Torogao, Ohogao, Ohhoai, Ikigao, Afterglow, In heat, Aroused, Naughty face и Seductive smile добавлены 22 варианта: закатившиеся глаза, слёзы и оскал, сердечки в зрачках, зажмуренные глаза, взгляд в сторону, влажные глаза, поцелуй, облизывание губ, язык у уголка рта, стиснутые зубы, умоляющий взгляд, пустые глаза, расширенные зрачки и другие комбинации. По умолчанию открыта вкладка SFW. Пресеты описывают мимику; некоторые специальные теги могут слабо распознаваться моделью.

В версии 0.6 из основной библиотеки убраны 19 близких повторов. Например, Seductive smile и несколько похожих вариантов флирта объединены в одну карточку; нервные улыбки и ожидание сведены к Nervous wait. Acmegao и Yogarigao убраны как близкие варианты Ikigao и Torogao. Старые ID остаются доступны узлам и прямому чтению кеша: уже сохранённые workflow работают, PNG и WebP не удаляются. Скрытые варианты не входят в счётчик и не генерируются общей кнопкой. Ключи наборов сохраняются.

Выберите лишний набор в списке и нажмите **Delete set**. Он исчезнет из активного списка; PNG, миниатюры и настройки переносятся в `user/emotional_gallery/.trash/`. **Restore deleted set** возвращает последний удалённый набор, включая изображения. Возможность восстановления сохраняется после обновления страницы в этом браузере. Если такой набор уже создан заново, восстановление не перезапишет его. Ранее удалённые наборы остаются в `.trash`; кнопка относится к последнему удалению. Удаление недоступно во время генерации этого набора.

Ноды остаются зарегистрированы на сервере для внутреннего генератора и совместимости с прежними workflow. Добавлять их пользователю не нужно. Выберите карточку в окне и нажмите **Copy expression**, затем вставьте теги в положительный промпт своего workflow.

Обычный клик по карточке выбирает эмоцию. Кнопка **Enlarge** или миниатюра выбранного выражения под карточками открывает исходное изображение крупно. Кнопки со стрелками и клавиши ← / → переключают готовые выражения текущей вкладки, Escape закрывает просмотр.

Настройки распределены по сворачиваемым разделам **Character**, **Model files**, **Trigger words**, **Prompts** и **Generation**. По умолчанию развёрнут только Character; если модель не выбрана, раздел её файлов раскрывается автоматически. Состояние разделов запоминается. Кнопка **Settings** скрывает боковую панель целиком. Добавление своей эмоции, удаление и восстановление набора находятся в меню **•••**.

## Свои эмоции

Нажмите **••• → + Custom expression**, введите название карточки, промпт выражения лица, категорию и подкатегорию. Например: **Скепсис** — `skeptical expression, one eyebrow raised, pursed lips`. Нажмите **Add expression**: откроется её вкладка и подкатегория, карточка появится в галерее и будет выбрана. **Generate missing** создаёт недостающие превью её подкатегории, а **Generate missing in set** включает все отсутствующие выражения.

Свои эмоции доступны для всех LoRA и сохраняются в `user/emotional_gallery/custom_emotions.json`. Добавление карточки сохраняет готовые изображения и прежние ключи кеша. Названия должны быть уникальными, до 80 символов; промпт — до 4000 символов. Промпт дополняет trigger words и базовый промпт персонажа.

После обновления расширения перезапустите ComfyUI и обновите страницу через Ctrl+F5. Готовые изображения из прежних версий сохраняются; изменение интерфейса не меняет ключ набора.

## Кеш и очередь

**Generate missing in group** и **Generate missing** внутри подкатегории продолжают выбранный сохранённый набор с его настройками и пропускают готовые карточки и задачи в очереди. Изменившиеся даты файлов модели не создают новый набор при такой догенерации. Если поля настроек не менялись, общая кнопка **Generate missing in set** работает так же. Изменение полей переключает общую кнопку на **Create gallery**: она выбирает набор по текущим файлам модели и новым настройкам.

Задачи галереи передают идентификатор окна ComfyUI: прогресс, завершение и ошибки приходят в окно, из которого запущена генерация. Это позволяет стандартным индикаторам и полосе rgthree сбрасываться после завершения. Запросы без идентификатора окна используют отдельный служебный идентификатор и не рассылают прогресс другим окнам.

- Кеш находится в `ComfyUI/user/emotional_gallery/` (либо в настроенном user directory): PNG, миниатюры WebP и JSON с параметрами.
- Сохраняется отдельный набор для каждой комбинации LoRA, модели, промптов, силы LoRA, seed и настроек семплинга. Для Anima также учитываются text encoder, VAE и shift. Размер, время изменения и путь файлов моделей входят в ключ кеша. Файлы LoRA не изменяются. Кеш SD из версии 0.1 сохраняет прежние ключи.
- Выбор LoRA открывает последний сохранённый набор. Другие наборы доступны в списке над карточками.
- **Generate missing in set** пропускает готовые и уже поставленные в очередь эмоции.
- Окно можно закрывать, страницу можно обновлять — уже поставленные задачи выполняет сервер ComfyUI. При перезапуске самого сервера незавершённые задачи теряются; готовые карточки сохраняются, остальные можно догенерировать.
- **Остановить оставшиеся** удаляет только ожидающие задачи этого набора. Текущая генерация завершается; другие workflow не прерываются.
- После изменения настроек карточки продолжают показывать предыдущий набор до нажатия генерации. Подпись над карточками сообщает об этом.

## Совместимость

Доступны профили локальных генераторов через штатные узлы ComfyUI. Платные API не используются; модели расширение не скачивает. После добавления файлов нажмите **Refresh models and LoRAs**.

| Профиль | Нужные файлы | Начальные параметры |
| --- | --- | --- |
| Anima | Diffusion model, Qwen3 0.6B, Qwen Image VAE | 768×768, 30 шагов, CFG 4 |
| Illustrious / NoobAI, Pony, SDXL | Checkpoint с энкодерами и VAE | 1024×1024, 28 шагов, CFG 5 (Pony: 6) |
| SD 1.5 | Полный checkpoint | 512×512, 24 шага, CFG 7 |
| Flux.1 Dev / Schnell | Diffusion model, CLIP-L, T5-XXL, Flux.1 / ae VAE | 1024×1024, 20 / 4 шага, CFG 1 |
| SD3 / SD3.5 | Checkpoint с VAE, отдельные CLIP-L, CLIP-G и T5-XXL | 1024×1024, 28 шагов, CFG 4.5 |
| Qwen Image | Diffusion model для text-to-image, Qwen2.5-VL 7B, Qwen Image VAE | 1024×1024, 30 шагов, CFG 4 |
| Z-Image Base / Turbo | Diffusion model, Qwen3 4B, Flux.1 / ae VAE | 1024×1024, 25 / 8 шагов, CFG 4 / 1 |

Параметры можно менять. При CFG 1 негативный промпт не участвует в CFG; Flux Dev имеет отдельное поле **Guidance** со стартовым значением 3.5. Каждый выбранный энкодер входит в ключ кеша; смена профиля создаёт отдельный набор.

Нужна версия ComfyUI со штатными узлами выбранной архитектуры. LoRA должна соответствовать модели: выбор профиля не преобразует LoRA между архитектурами. GGUF, Flux.2, модели редактирования и генерация видео требуют других workflow и пока не включены. Подробности и ссылки на штатные примеры — в [английской инструкции](README.md).

131 встроенное выражение — начальная библиотека, которую можно дополнить своими эмоциями, а не все возможные выражения. Качество и узнаваемость персонажа зависят от модели, LoRA и trigger words; некоторые LoRA слабо реагируют на выражения лица. Превью не гарантирует сохранение выражения или композиции в другом workflow.

## Проверки

Из исходного репозитория можно собрать ZIP для установки, текст релиза и контрольную сумму SHA-256:

```powershell
python scripts/build_release.py
```

Файлы появятся в `dist/v1.0.0/`. ZIP распаковывается прямо в `ComfyUI/custom_nodes/` и содержит папку `comfyui_emotional_gallery`. В архив входят только файлы расширения, документация, лицензия и установщик.

```powershell
python -m unittest discover -s tests -v
node --check web/gallery.js
```

## Публикация в Comfy Registry

Workflow [Publish to Comfy Registry](.github/workflows/publish-registry.yml) запускается при **публикации стабильного GitHub Release**. Он берёт код из коммита релиза, сверяет тег с `v<project.version>`, запускает тесты Python и JavaScript, собирает ZIP и отправляет расширение официальным action Comfy. Черновики, prerelease и обычные push публикацию не запускают.

Настройка один раз:

1. Создайте **Registry Publishing API Key** для издателя `nikminer` в [Comfy Registry](https://registry.comfy.org/). В `pyproject.toml` уже указан `PublisherId = "nikminer"`.
2. В репозитории GitHub откройте **Settings → Secrets and variables → Actions → New repository secret**. Имя секрета — `REGISTRY_ACCESS_TOKEN`, значение — ключ реестра. [Официальная инструкция](https://docs.comfy.org/registry/publishing).
3. Закоммитьте и отправьте workflow, `.comfyignore`, метаданные и исходники релиза до создания тега.

Для каждого релиза обновите `project.version` и `CHANGELOG.md`, затем опубликуйте GitHub Release с соответствующим тегом: например, **v1.0.0** для версии **1.0.0**. Результат появится в **Actions → Publish to Comfy Registry**. ZIP на этапе проверок временный; официальный action упаковывает отслеживаемые Git файлы с учётом `.comfyignore`, исключая тесты и инструменты разработки.

Отсутствующий ключ или ошибка проверок останавливают публикацию. После добавления недостающего секрета можно нажать **Re-run failed jobs** в запуске workflow. Версию в реестре нельзя перезаписать: следующие изменения выпускайте с новым номером и тегом.

Интерфейс зарегистрирован через [JavaScript Extensions API](https://docs.comfy.org/custom-nodes/js/javascript_overview), Python-узлы — через [custom node API](https://docs.comfy.org/custom-nodes/backend/server_overview). Генерации выполняет штатная очередь ComfyUI.
